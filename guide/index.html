备赛资料 ​

📚 系统化整理的 RoboMaster 备赛资料，覆盖机械、电控、视觉、算法四大方向

🗺️ 学习路线图 ​

新人入门路径 ​

第 1 步：了解 RM

阅读 RoboMaster 官网，观看比赛视频，了解比赛规则和机器人兵种

第 2 步：选择方向

根据兴趣和基础选择机械/电控/视觉/算法方向，每个方向都有不同的技能要求

第 3 步：环境搭建

根据所选方向搭建开发环境（IDE、工具链、仿真平台等）

第 4 步：基础学习

学习该方向的基础知识，完成入门小项目

第 5 步：实战练习

参与战队项目，在实战中成长

四大方向 ​

🛠️ 机械方向 → ​

  • 核心技能：SolidWorks 建模、材料力学、机械原理、有限元分析
  • 工作内容：机器人底盘/云台/发射机构设计、减重优化、加工装配
  • 推荐工具：SolidWorks, AutoCAD, ANSYS

⚡ 电控方向 → ​

  • 核心技能：STM32 开发、嵌入式 C 语言、PID 控制、CAN 通信
  • 工作内容：电机驱动、传感器读取、遥控器通信、底盘/云台控制
  • 推荐工具：Keil/STM32CubeIDE, J-Link, 示波器

👁️ 视觉方向 → ​

  • 核心技能：OpenCV、目标检测（YOLO）、相机标定、C++/Python
  • 工作内容：装甲板识别、能量机关击打、自动瞄准、双目测距
  • 推荐工具：OpenCV, YOLOv8/v11, CMake, Ubuntu

🧠 算法方向 → ​

  • 核心技能：ROS2、路径规划、运动控制、卡尔曼滤波
  • 工作内容：哨兵导航、决策树、状态机、仿真模拟
  • 推荐工具：ROS2, Gazebo, Eigen, Ceres
