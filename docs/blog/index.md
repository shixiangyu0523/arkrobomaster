## ✍️ 如何投稿

1. 在 `docs/blog/` 目录下创建 Markdown 文件
2. 文件名格式：`YYYY-MM-DD-标题.md`
3. 使用 Frontmatter 声明文章信息
4. 提交 PR，审核通过后即可发布

### 文章模板

```markdown
---
title: 文章标题
date: 2026-01-01
author: 你的名字
tags: [视觉, YOLO]
---

## 正文开始...
```

### 技术博客写作指南
- 写清楚**背景**（为什么做这个）
- 写清楚**过程**（怎么做的，遇到了什么问题）
- 写清楚**结论**（效果如何，有什么收获）
- 附上代码链接或关键代码片段

---

::: tip 为什么要写技术博客？
写博客是最好的学习方式之一。把知识输出成文字，你会发现自己理解得更深。同时也是你个人技术品牌的积累。
:::
