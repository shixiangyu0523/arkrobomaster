# 战队介绍

## 我们是谁

**ARK（云龙）战队** 是徐州工程学院的 RoboMaster 机甲大师参赛战队。

> "ARK" — 方舟，承载梦想，驶向星辰大海。
> "云龙" — 取自徐州云龙山/云龙湖，根植彭城大地，志在九天云霄。

::: tip 我们是初创战队
ARK 是一支全新组建的战队，正在为 RM2027 赛季积极备赛。虽然我们是新队伍，但我们有热情、有冲劲、有不服输的精神！
:::

## 战队文化

### 🎯 使命
以赛促学，以赛促创。通过 RoboMaster 比赛，培养队员在机械设计、嵌入式系统、计算机视觉、自动化控制等领域的综合工程能力。

### 🏆 精神
- **极致**：追求每一个细节的完美
- **竞争**：在赛场上证明自己
- **疯狂**：为热爱全力以赴

### 🤝 传承
我们相信：**"把机器人造出来，把能力练出来，把经验传下去"**

## 战队架构

ARK 战队按技术方向分为以下组别：

<div class="rm-card">

### 🛠️ 机械组
负责机器人结构设计、有限元分析、加工装配。使用 **SolidWorks** 进行 3D 建模，涵盖底盘、云台、发射机构等核心结构。

**核心技能**：SolidWorks、材料力学、机械原理、3D 打印/CNC 加工

</div>

<div class="rm-card">

### ⚡ 电控组
负责嵌入式系统开发、电机控制、传感器数据采集、通信协议实现。主控使用 **STM32** 系列，驱动 DJI M3508/M2006/GM6020 等电机。

**核心技能**：STM32、嵌入式 C、PID 控制、CAN 通信

</div>

<div class="rm-card">

### 👁️ 视觉组
负责目标检测、自动瞄准、定位导航。使用 **OpenCV** + **YOLO** 系列算法，实现对装甲板的精准识别和自动瞄准。

**核心技能**：OpenCV、YOLOv8+、C++/Python、Linux

</div>

<div class="rm-card">

### 🧠 算法组
负责路径规划、决策算法、运动控制算法。使用 **ROS2** + **C++/Python**，涵盖哨兵全自动导航、仿真模拟等。

**核心技能**：ROS2、路径规划、SLAM、卡尔曼滤波

</div>
