# 电控方向

> ⚡ 负责机器人的 **嵌入式系统开发、电机控制、传感器数据采集、通信实现**

---

## 学习路线

### 第一阶段：基础入门
1. **C 语言基础**：指针、结构体、内存管理
2. **STM32 入门**：GPIO、定时器、中断、串口通信
3. **电路基础**：基本电路分析、常见传感器原理
4. **开发工具链**：Keil / STM32CubeIDE / CLion

### 第二阶段：专业进阶
1. **PID 控制**：位置式/增量式 PID、参数整定
2. **CAN 通信**：CAN 总线协议、电机通信（DJI 电机协议）
3. **FreeRTOS**：任务调度、消息队列、信号量
4. **电机控制**：M3508/M2006/GM6020 电机驱动

### 第三阶段：实战应用
1. **底盘控制**：麦克纳姆轮解算、遥控器解析、功率限制（RM2027：英雄600W）
2. **云台控制**：双轴云台稳定、IMU 姿态解算
3. **发射控制**：摩擦轮调速（RM2027：42mm 热量管理+冷却机制）、拨弹控制
4. **系统联调**：裁判系统对接（UDP + MQTT/ProtoBuf）、UI 显示、RJ45 千兆通信

## 硬件平台

| 硬件 | 说明 |
|------|------|
| **STM32F407/F427** | 主控芯片（常用） |
| **DJI M3508** | 减速电机（底盘） |
| **DJI M2006** | 减速电机（云台/拨弹） |
| **DJI GM6020** | 无刷直驱电机（云台） |
| **DJI C620/C610** | 电调 |
| **MPU6050/ICM20602** | IMU 惯性测量单元 |
